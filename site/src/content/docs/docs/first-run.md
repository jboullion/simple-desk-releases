When you open Simple Desk you land on **Home**: a card for each app, your recent files, and buttons to open a file or
join a shared document.

## Your library

The library is the folder where Simple Desk keeps your documents. It starts as `Documents/Simple Desk` and is created
the first time you need it. It's a normal folder: you can open it in Explorer or Finder, back it up, or put it in a
cloud-synced folder (see [Using several computers](/docs/several-computers/)).

To move it, go to **Settings → Files → Change location…**. Simple Desk offers to move your existing files to the new
place.

## The Files panel

The Files panel (the folder button at the top left, or **Ctrl+Shift+E**) shows the real folders on your disk:

- **Library**: your library folder.
- **Locations**: other folders you add with **Add location…**, for example a project folder or a USB drive.

Click a file to open it in its app. Right-click for **New file**, **New folder**, **Rename** (F2), **Move to Recycle
Bin** (Del) and **Reveal in Explorer** (Finder on a Mac). Drag rows to move them between folders, or drop files from
your computer onto a folder to copy them in. The Open and Save dialogs start in the folder you selected.

## Choosing your apps

**Settings → Apps** turns apps on or off. Turned-off apps disappear from Home, the sidebar, the command palette and the
**New** menu, but their files still open when you double-click one.

To-do, Calculator, Meme Maker, Images, the API client and JSON start turned off to keep things simple. Turn on the ones
you want.

Each app has its own color (Markdown blue, CSV green, PDF red, Paint pink, Board violet and so on). Its icon uses that
color everywhere: the sidebar, Home, tabs, the Files panel and the command palette, so file types are easy to tell
apart.

## Light and dark

**Settings → General → Appearance** switches between Light, Dark, or following your system.

## The command palette

Press **Ctrl+K** for a searchable list of everything: new documents, recent files, open tabs, settings and commands
like **Ask AI** or **Join shared document**. Type a few letters and press Enter.
