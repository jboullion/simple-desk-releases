---
title: Updates
description: How Simple Desk checks for and installs new versions.
---

Simple Desk checks for a new version a few seconds after it starts and every six hours after that. When one is out, an
update icon appears above Settings (in the header on Android).

## Installing an update

Open **Settings → About** (or click the update icon). It shows the new version's notes and:

- **Update and restart** on Windows, macOS and Linux. On Windows the installer runs and the app comes back; on macOS
  and Linux the app is replaced and restarts. A `.deb` or `.rpm` install asks for your password. If you have unsaved
  documents, Simple Desk asks first.
- **Download and install** on Android. The system installer asks you to confirm (the first time, allow Simple Desk to
  install apps).
- **Skip this version**, to stop being reminded about this one. You'll still hear about the next.

Updates are signed, and the app only installs files from this project's
[GitHub releases](https://github.com/jboullion/simple-desk-releases/releases).

## Turning off automatic checks

Turn off **Check for updates automatically** in Settings → About. You can still click **Check now** whenever you like.

## Release notes

The [download page](/download/) shows what's new in the current version, and every release is listed on
[GitHub](https://github.com/jboullion/simple-desk-releases/releases).
