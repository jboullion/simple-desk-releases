---
title: Using several computers
description: Keep your library in a OneDrive, Dropbox or Google Drive folder to have your files everywhere.
---

Simple Desk doesn't sync anything itself. To have the same documents on more than one computer, keep your library in
a folder that a sync service already handles, such as OneDrive, Dropbox or Google Drive.

## Set it up

1. Install the sync app (OneDrive, Dropbox, Google Drive for desktop…) on each computer and sign in.
2. In Simple Desk, open **Settings → Files → Change location…** and pick a folder inside the synced folder, for
   example `OneDrive/Simple Desk`. Let Simple Desk move your existing files there.
3. On your other computers, install Simple Desk and point the library at the same synced folder.

Your documents now follow you. Because they're plain files, you can also open them from the sync service's website or
phone app.

## Good to know

- **Close a document on one computer before editing it on another.** Sync services copy whole files; if the same file is
  changed in two places before they sync, the service keeps both (usually as a "conflicted copy").
- **To-dos and settings stay on each device.** They live in the app's own settings, not in the library.
- **Make sure files are downloaded.** "Files on demand" features may keep only placeholders on disk; mark the library
  folder "Always keep on this device" if a file won't open.
- **Working on a document together, at the same time?** Use [live sharing](/docs/sharing/live-sharing/) instead.
