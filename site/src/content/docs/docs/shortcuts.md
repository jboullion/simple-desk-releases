---
title: Keyboard shortcuts
description: The keyboard shortcuts in Simple Desk, everywhere and per app.
---

On a Mac, the shortcuts below use **Ctrl** for now, not Cmd.

## Everywhere

| Shortcut | Does |
|---|---|
| Ctrl+K | Command palette: commands, apps, recent files |
| Ctrl+, | Settings |
| Ctrl+Shift+E | Show or hide the Files panel |
| Ctrl+Shift+A | Show or hide the AI sidebar |
| Ctrl+O | Open a file |
| Ctrl+N | New document |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save as |
| Ctrl+W | Close the tab |
| Ctrl+Tab | Next tab |
| F2 | Rename (Files panel) |
| Del | Move to Recycle Bin / Trash (Files panel) |

## Markdown

| Shortcut | Does |
|---|---|
| Ctrl+B / Ctrl+I | Bold / italic |
| Ctrl+E | Inline code |
| Ctrl+click | Open a link in the preview |
| Ctrl+Z / Ctrl+Y | Undo / redo |

## CSV

| Shortcut | Does |
|---|---|
| Enter / Tab | Move down / right |
| Alt+Enter | New line inside a cell |
| Ctrl+C / X / V | Copy, cut, paste (works with Excel and Google Sheets) |
| Ctrl+D / Ctrl+R | Fill down / right |
| Ctrl+F / Ctrl+H | Find / replace |
| Ctrl+Z / Ctrl+Y | Undo / redo |

## PDF

| Shortcut | Does |
|---|---|
| Ctrl+F | Find |
| Ctrl+plus / minus / 0 | Zoom in, out, reset (or Ctrl+wheel) |
| Ctrl+Z | Undo |

## Paint

| Shortcut | Does |
|---|---|
| X | Swap color 1 and color 2 |
| [ / ] | Smaller / bigger tool |
| Ctrl+A, Ctrl+C / X / V | Select all, copy, cut, paste |
| Space+drag or middle-drag | Pan |
| Ctrl+wheel | Zoom at the cursor |
| Shift while drawing | Square, circle or 45° line |

## Board

| Shortcut | Does |
|---|---|
| V | Select |
| H (or Space, middle-drag) | Hand: pan |
| N | Sticky note |
| T | Text |
| S | Shapes |
| L | Connector |
| P | Pen |
| F | Frame |
| C | Comment |
| Ctrl+C / V / D | Copy, paste, duplicate |
| Ctrl+wheel | Zoom |

## Meme Maker

| Shortcut | Does |
|---|---|
| Double-click or Enter | Edit text |
| Del | Delete |
| Ctrl+D | Duplicate |
| Arrows (Shift ×10) | Nudge |
| Ctrl+Z / Ctrl+Y | Undo / redo |
| Ctrl+Shift+C | Copy the image |
| Esc | Deselect |

## Calculator and graphs

| Shortcut | Does |
|---|---|
| Enter | Add the line to the history |
| ↑ / ↓ | Recall earlier lines |
| Arrows, + / −, 0 | Pan, zoom and reset the graph (when it has focus) |
| Wheel (Shift: x only, Alt: y only) | Zoom the graph |

## JSON and API client

| Shortcut | Does |
|---|---|
| Shift+Alt+F | Format JSON |
| Ctrl+Enter | Send the request (API client) |
