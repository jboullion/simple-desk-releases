title: Live sharing
description: Edit a Markdown document together with other people, live and end-to-end encrypted, with no accounts.

Edit a Markdown document together with other people, live, on desktop and Android. There are no accounts: anyone with
the link can join.

## Share a document

1. Open a Markdown file and press the **people** button in its toolbar → **Share this document**.
2. Send the link, the invite code, or let a phone scan the QR code.

Anyone with the link can read and edit the document, so send it only to people you trust.

## Join

Click the link, or paste it in **Home → Join shared…** (or **Ctrl+K → Join shared document**). The document is saved in
your library under `Shared` and opens.

## Working together

- Everyone's edits appear as they type, each with a named cursor; avatars show who's there. Your name is set in
  **Settings → General**.
- **Ctrl+Z** undoes only your own edits.
- The file saves itself, so it's always an ordinary Markdown file on each person's disk.

## Offline

Edits made without a connection merge when you're back online. If you edit the file in another program, the change is
merged in; if that isn't possible, the shared text is kept and your version is saved next to it as
`name (changed outside <date>).md`.

## Private by design

Everything is **end-to-end encrypted** on your device. The key is the part of the link after `#`, which never reaches a
server; the sharing server (the relay) only passes along data it can't read. More in the
[privacy policy](/privacy/#live-sharing-optional).

To remove someone, **Stop sharing** and share again: that makes a new link. **Settings → Sharing** lists your shared
documents and the server new shares use.
